# GameVault

Интерактивный каталог видеоигр и персональный трекер бэклога в эстетике интерфейса PlayStation 5.

**Демо:** [https://lelyaler.github.io/React-TypeScript/](https://lelyaler.github.io/React-TypeScript/)

---

## О проекте

Большинство существующих трекеров игровой коллекции (Backloggd, HowLongToBeat или таблицы в Notion) представляют собой статичные списки и таблицы. Основная цель GameVault — перенести тактильный опыт и визуальную динамику консольных интерфейсов (PS5 Dashboard) в современный веб, сохранив высокую производительность, мгновенный оффлайн-доступ и удобство управления с любого устройства.

## Ключевые инженерные решения

### 1. Оптимизация производительности и Core Web Vitals (LCP < 1.2s)
- **Многоуровневая обработка графики**: для каждой игры подготовлены лёгкие капсулы и широкоформатные бэкдропы (1376×768) в формате WebP с адаптивными версиями для мобильных экранов.
- **Приоритизация загрузки**: главный экранный арт текущей игры загружается с атрибутами `fetchpriority="high"` и декодированием `async`, в то время как фоновые ассеты и модальные слои подгружаются лениво через `React.lazy` и `Suspense`.
- **Консольная полка без рефлоу**: плавная горизонтальная прокрутка списка игр использует аппаратное ускорение `transform: translate3d` без пересчёта геометрии документа при фокусе.

### 2. Поддержка геймпадов через Gamepad API
- Реализован кастомный хук `useGamepad`, обрабатывающий опрос состояния контроллеров (DualSense, DualShock, Xbox Controller) через `requestAnimationFrame`.
- Встроен алгоритм кулдауна (200 мс) для предотвращения дребезга ввода на аналоговых стиках и D-Pad.
- Полный маппинг консольных действий: навигация крестовиной/стиком, открытие карточки (✕), быстрый цикл статуса в бэклоге (□), выбор случайного тайтла (△) и закрытие модалок (○).

### 3. Двусторонняя синхронизация состояния с URL
- Все фильтры каталога, поисковые запросы, выбранный режим отображения (консоль/сетка) и слаг активной игры транслируются в URL Query Parameters через кастомный хук `useUrlSync`.
- Поддерживается история браузера (`popstate`), благодаря чему ссылкой на конкретную игру или отфильтрованный каталог можно делиться напрямую.

### 4. Оффлайн-first архитектура и интеграции
- Локальный датасет на 36 культовых тайтлов исключает задержки сетевых запросов и зависимость от лимитов сторонних API при первом визите.
- Поддержка подключения персонального RAWG REST API ключа для расширенного поиска по базе из сотен тысяч игр.
- Резервное копирование бэклога в формате JSON и импорт библиотеки из аккаунта Steam (через Web API / ID).

## Стек технологий

* **Фреймворк**: React 19
* **Язык**: TypeScript (строгая типизация всех сущностей и пропсов)
* **Стилизация**: Tailwind CSS v4, Lucide React
* **Сборка и проверка**: Vite 8, Vitest, oxlint, TypeScript Compiler (`tsc -b`)
* **Браузерные интерфейсы**: Gamepad API, Web Share API, Clipboard API, Service Workers

## Архитектура проекта

```
src/
├── components/          # Компоненты интерфейса
│   ├── game-details/    # Вкладки детального просмотра (обзор, скриншоты, требования)
│   ├── ui/              # Базовые UI-примитивы (Badge, Modal, Toast)
│   ├── PS5Backdrop.tsx  # Динамический широкоформатный арт с мягким градиентом
│   ├── PS5Spotlight.tsx # Информационная панель с быстрым управлением
│   ├── PS5GameShelf.tsx # Интерактивная полка тайтлов
│   └── ModalLayer.tsx   # Изолированный слой ленивых модальных окон
├── data/                # Встроенный оффлайн-каталог и оптимизированные ассеты
├── hooks/               # Модульные хуки бизнес-логики
│   ├── useGamepad.ts           # Интеграция с Gamepad API
│   ├── useKeyboardShortcuts.ts # Клавиатурная навигация
│   ├── useLibraryActions.ts    # Экспорт, импорт JSON/Steam, Web Share
│   ├── useBacklog.ts           # Управление состоянием бэклога и рейтингами
│   ├── useGames.ts             # Интеграция с каталогом и RAWG API
│   └── useUrlSync.ts           # Синхронизация состояния с адресной строкой
├── types/               # TypeScript интерфейсы сущностей
└── utils/               # Чистые функции фильтрации, сортировки и валидации
```

## Управление

| Действие | Клавиатура | Геймпад (PlayStation / Xbox) |
| :--- | :--- | :--- |
| **Навигация по полке** | `←` / `→` | D-Pad `Left` / `Right` или Левый стик |
| **Выбрать игру / Подробнее** | `Enter` | `✕` / `A` |
| **Назад / Закрыть модалку** | `Esc` | `○` / `B` |
| **Сменить статус в бэклоге** | Клик по кнопке | `□` / `X` |
| **Случайная игра** | Кнопка «Случайная» | `△` / `Y` |
| **Быстрый фокус на поиск** | `/` | — |

## Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/lelyaler/React-TypeScript.git
cd React-TypeScript

# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Запуск тестов
npm test

# Сборка оптимизированного бандла
npm run build
```
