# GameVault

> **Live Demo:** [https://lelyaler.github.io/React-TypeScript/](https://lelyaler.github.io/React-TypeScript/)

Веб-приложение для каталогизации и трекинга видеоигр (бэклог) в стилистике интерфейса PlayStation 5.

Работает как со встроенным демо-каталогом (с трейлерами и скриншотами), так и с полным API RAWG (более 500 000 игр).

## Основные возможности

- **Интерфейс в стиле PS5**: динамический фон активной игры, консольная полка с автоскроллом и фокус-баннер.
- **Адаптивность**: при уменьшении экрана или на мобильных устройствах интерфейс автоматически перестраивается в удобную вертикальную сетку без пустот.
- **Геймпад**: нативная навигация с контроллеров DualSense / Xbox через Gamepad API.
- **Звук**: процедурный аудиоотклик интерфейса на Web Audio API (без внешних аудиофайлов).
- **Бэклог**: статусы («Играю», «В планах», «Пройдено»), личные оценки (1-5 звёзд), статистика и экспорт в JSON.
- **Рулетка**: встроенный рандомайзер для случайного выбора игры.
- **Deep Linking**: синхронизация фильтров, поиска и открытой игры с адресной строкой (URLSearchParams).
- **Превью скриншотов**: автоматическое слайд-шоу скриншотов при наведении на карточку.
- **Медиа**: трейлеры игр в 16:9, галерея скриншотов и системные требования для ПК.
