# GameVault

Интерактивный каталог видеоигр и трекер бэклога в эстетике консольного интерфейса PlayStation 5.

**Демо:** [https://lelyaler.github.io/React-TypeScript/](https://lelyaler.github.io/React-TypeScript/)

## Особенности

- **Консольный UX**: плавная круговая полка игр с динамическим бэкдропом и превью.
- **Поддержка геймпадов**: полноценная навигация с DualSense и контроллеров Xbox через Gamepad API.
- **Процедурный звук**: системные звуки интерфейса синтезируются в реальном времени через Web Audio API.
- **Бэклог и библиотека**: трекинг статусов («Играю», «В планах», «Пройдено»), личные оценки и заметки, экспорт/импорт в JSON и Steam.
- **Каталог и фильтры**: встроенный оффлайн-каталог на 36 тайтлов + поддержка RAWG REST API, поиск и сохранение состояния в URL.
- **PWA**: оффлайн-кэширование и возможность установки как веб-приложения.

## Стек

- React 19 / TypeScript / Vite
- Tailwind CSS v4
- Web Audio API / Gamepad API
- Vitest
